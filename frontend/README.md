# Eunoia Frontend

This directory contains the Expo Router React Native app for Eunoia.

The full project documentation, setup guide, environment configuration, feature map, backend API reference, and architecture diagrams live in the root [README.md](../README.md).

Quick start from this directory:

```powershell
Copy-Item .env.example .env
npm install
npm run start
```

Set `EXPO_PUBLIC_BACKEND_URL` in `.env` before running on a device or emulator.
